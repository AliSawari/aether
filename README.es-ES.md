

# Aether

[![Build](https://github.com/AliSawari/aether/actions/workflows/build.yml/badge.svg)](https://github.com/AliSawari/aether/actions/workflows/build.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**WireGuard, refinado.**

Una aplicación de escritorio independiente para Linux para gestionar conexiones VPN de WireGuard. Elige cualquier carpeta de trabajo, importa las configuraciones del proveedor y conéctate con un solo clic.

## Características

- Directorio de área de trabajo elegido por el usuario (cualquier carpeta en el disco)
- Generador de configuraciones nativo en Rust (no se requiere Node.js en tiempo de ejecución)
- Detección automática de WiFi/Ethernet y generación de configuraciones divididas `smart*-wifi` / `smart*-eth`
- Páginas de Inicio y Configuración con estado de conexión sincronizado
- Bandeja del sistema con conexión/desconexión rápida
- Interfaz de usuario moderna y oscura con estado en vivo, estadísticas de transferencia e información de handshake
- Elevación de privilegios única (opcional) para que la conexión/desconexión omita la solicitud de contraseña

## Instalación

### Desde una versión publicada (recomendado)

Descarga la última versión para **Linux x86_64**:

| Formato | Caso de uso |
|--------|----------|
| `.deb` | Instalación para Debian/Ubuntu |
| `.AppImage` | Ejecutable portátil, sin instalación |

**Debian / Ubuntu**

```bash
sudo dpkg -i Aether_*.deb
sudo apt-get install -f   # if dependencies are missing
```

**AppImage**

```bash
chmod +x Aether_*.AppImage
./Aether_*.AppImage
```

### Dependencias en tiempo de ejecución

- `wireguard-tools` (`wg`, `wg-quick`)
- PolicyKit (`pkexec`) — solo hasta que uses **Autorizar una vez**

```bash
sudo apt install wireguard-tools policykit-1
```

## Estructura del área de trabajo

Elige cualquier carpeta que contenga directamente los archivos `.conf` de WireGuard del proveedor:

```
/your/workspace/
├── provider-smart1.conf   # provider configs (scanned from this folder only)
├── provider-smart2.conf
├── smart1-wifi.conf       # generated by Aether
├── smart1-eth.conf
└── ...
```

Los archivos generados `smart*-wifi.conf` / `smart*-eth.conf` se ignoran al listar los servidores.

La configuración se almacena en `~/.config/aether/settings.json`.

## Desarrollo

### Requisitos previos

- Rust **1.88+** (fijado en `rust-toolchain.toml`)
- Node.js **20+**
- Dependencias de Tauri para Linux:

```bash
sudo apt install \
  libwebkit2gtk-4.1-dev \
  libayatana-appindicator3-dev \
  librsvg2-dev \
  build-essential
```

### Ejecutar localmente

```bash
npm install
npm run tauri dev
```

### Compilación para producción

```bash
npm run tauri build
```

Los paquetes se guardan en `src-tauri/target/release/bundle/` (`.deb`, AppImage y el binario independiente).

## CI / Versiones

| Flujo de trabajo | Activador | Salida |
|----------|---------|--------|
| [Build](.github/workflows/build.yml) | Push / PR a `master` | Artefactos `.deb` + AppImage (retención de 90 días) |
| [Release](.github/workflows/release.yml) | Publicación de versión en GitHub | Paquetes adjuntos a la versión + resumen del registro de cambios |

**Crear una versión**

```bash
git tag v0.1.0
git push origin v0.1.0
```

Crea y publica la versión en GitHub desde esa etiqueta. El flujo de trabajo de versiones compila los paquetes para Linux x86_64, agrega una sección de **Qué ha cambiado** y sube los archivos.

Consulta [CHANGELOG.md](CHANGELOG.md) para el historial de versiones.

## Opcional: elevación sin contraseña

Aether no almacena tu contraseña de sudo. Usa **Autorizar una vez** en la barra lateral: esto instala una regla restrictiva de sudoers + PolicyKit solo para `wgctl.sh` incluido en Aether (un único prompt de contraseña).

O manualmente:

```bash
sudo cp polkit/aether.rules /etc/polkit-1/rules.d/50-aether.rules
```

## Arquitectura

| Componente | Función |
|-----------|------|
| `src-tauri/src/generator.rs` | Regenera `smart*-wifi/eth.conf` desde las configuraciones del proveedor |
| `src-tauri/src/wg.rs` | Analiza la salida de `wg show` para el estado en vivo |
| `src-tauri/src/commands.rs` | Comandos de Tauri, elevación de privilegios, orquestación de `wgctl` |
| `scripts/wgctl.sh` | Conectar / desconectar / reiniciar (incluido en las versiones) |
| Frontend en Svelte | Interfaz de usuario, selector de área de trabajo, tarjetas de servidor, bandeja |
