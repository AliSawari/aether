# Aether

[![Build](https://github.com/AliSawari/aether/actions/workflows/build.yml/badge.svg)](https://github.com/AliSawari/aether/actions/workflows/build.yml)

**WireGuard, refined.**

A standalone Linux desktop app for managing WireGuard VPN connections. Pick any workspace folder, import provider configs, and connect with one click.

## Features

- User-chosen workspace directory (any folder on disk)
- Native Rust config generator (no Node.js required)
- Auto-detect WiFi/Ethernet and generate split configs
- System tray with quick connect/disconnect
- Dark modern UI with live connection status

## Workspace Layout

Pick any folder that contains provider WireGuard `.conf` files directly:

```
/your/workspace/
├── X2511328_SMART1.conf   # provider configs (scanned from this folder only)
├── X2511328_SMART2.conf
├── smart1-wifi.conf       # generated by Aether
├── smart1-eth.conf
└── ...
```

Generated `smart*-wifi.conf` / `smart*-eth.conf` files are ignored when listing servers.

Settings are stored in `~/.config/aether/settings.json`.

## Prerequisites

### Runtime (end users)

- `wireguard-tools` (`wg`, `wg-quick`)
- PolicyKit (`pkexec`)

### Build

- Rust **1.88+** (pinned in `rust-toolchain.toml`)
- Node.js 20+ (dev/build tooling only)
- Tauri Linux deps:

```bash
sudo apt install libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev
```

## Build & Run

```bash
cd tauri
npm install
npm run tauri dev
```

Production build:

```bash
npm run tauri build
```

## Releases

Publish a release on GitHub (tag e.g. `v0.1.0`). The [Release workflow](.github/workflows/release.yml) builds Linux x86_64 `.deb` and AppImage bundles, appends a changelog summary, and attaches them to the release.

```bash
git tag v0.1.0
git push origin v0.1.0
# Then create the release on GitHub from that tag
```

## Optional: Passwordless elevation

Aether will not store your sudo password. Instead, use **Authorize once** in the sidebar —
this installs a narrow sudoers + PolicyKit rule for Aether's `wgctl.sh` only (one password prompt).

Or manually:

```bash
sudo cp polkit/aether.rules /etc/polkit-1/rules.d/50-aether.rules
```

## Architecture

| Component | Role |
|-----------|------|
| `src-tauri/src/generator.rs` | Regenerates `smart*-wifi/eth.conf` from `original/` |
| `scripts/wgctl.sh` | Connect / disconnect / restart (bundled) |
| Svelte frontend | UI, workspace picker, server cards, tray |
